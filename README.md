# Image Tinker

> A lightweight, browser-based image editor built on HTML Canvas.

## Tech Stack

- **React + TypeScript**
- **HTML Canvas**
- **Zustand**
- **Tailwind**

## Getting Started

### Prerequisites

- Node.js v18+
- npm

### Installation

1. Clone the repo

```bash
   git clone https://github.com/yourname/image-tinker.git
```

2. Install dependencies

```bash
   cd image-tinker
   npm install
```

3. Start the dev server

```bash
   npm run dev
```

4. Open `http://localhost:5173`
